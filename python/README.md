# Транслятор, симулятор процессора

## Транслятор (translator.py)

1. Использование argparse (входные и выходные параметры).
2. Классовая структура - просто инкапсуляция состояния.
3. Применение struct.pack — перевод в бинарные числа
4. Строгая типизация (typing) с использованием MyPy

---

1. Псевдоинструкции (Pseudo-instructions): В секции внизу парсера я добавил обработку инструкций типа j и beqz. В настоящем RISC-V нет отдельной команды j. Там используется jal zero, offset (сохранить адрес возврата в zero, то есть отбросить его, и прыгнуть)
2. Смещение (Offset) в метках: Обратите внимание на строки return target_address - current_address. Во всех B и J инструкциях сохраняется не абсолютный адрес прыжка, а расстояние (сколько байт пропрыгать вперёд или назад). Благодаря этому откомпилированный код получается позиционно-независимым.
3. Ввод-вывод (Port-mapped I/O): Обычные инструкции памяти (lw/sw) обращаются к Data Memory. А мы ввели свои инструкции in и out (код 0x73), которые будут сигнализировать Control Unit, что мы обращаемся именно к портам. Это идеально закрывает ваше требование port из варианта.
4. Тип строк cstr: В блоке elif directive == ".string": я явно добавил + b'\x00' и выровнял память до границы машинного слова. Это реализует Null-terminated strings.

## Симулятор процессора (machine.py)

1. `harv` (Гарвардская архитектура): конструктор Processor.__init__. - туда передаются два физически разных объекта памяти: text_mem (List[int]) и data_mem (bytearray). Они никак не пересекаются.
2. `cache` (Кэш): класс CacheL1. В нем метод read возвращает задержку (stalls). А в методе tick() мы пишем if self.stall_cycles > 0: return. Это "замораживает" процессор на 10 тактов при кэш-промахе.
3. `hw` (Control Unit): Покажите класс ControlUnit. Там нет микрокода, только жесткие условия if opcode == ..., которые имитируют работу дешифратора на вентилях.
4. `trap` (Прерывания): Обратите внимание на конец метода tick(). Если interrupt_pending, то EPC сохраняет следующий PC, а PC переписывается на 0x0004. Инструкция iret потом возвращает PC обратно из EPC.
5. `tick` (Точность до такта): Каждое обращение к методу tick() инкрементирует счетчик на 1. Модель не "перепрыгивает" во времени, она ждет Stall честно такт за тактом.

---

### Control Unit

- аппаратно (hw) "разрезает" 32-битную инструкцию и генерирует управляющие сигналы (signals).

### Data Path

- потактовое выполнение и журналирование (tick-accurate).
